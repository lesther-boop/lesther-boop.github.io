嬰幼兒聽力檢查有哪些呢?

2024/10/26｜嬰幼兒聽力

兒童聽覺照護專家會同時使用數種方法進行聽力檢查，檢查的結果將會用聽力圖加以記錄，用來判定孩子的聽力損失類型與程度。兒童可能年紀太小，無法遵從指令，太緊張而無法安坐，也有可能只是沒有心情接受測試，所以為兒童進行聽力檢查相當具有挑戰性，愛心耐心為小朋友檢查聽力是維膜強項之一，而且我們有信心一直持續。

行為聽力檢查

主觀聽力檢查是評估聽力的主要方法，可用來確認聽力損失的類型跟程度，常用作診斷跟治療的基礎。 以下為各種判斷兒童主觀聽覺閾值的方法：

行為觀察聽力檢查 BOA ( behavioural observation audiometry )

利用在新生兒聽到聲音後會出現的反射反應，新生兒正常的感知閾值大概在80 dB HL左右。 測試時，透過喇叭或耳機播放短暫窄頻聲音，聽力師會仔細觀察嬰幼兒是否對聲音有任何反射行為，以及誘發反應的音量大小。

視覺增強聽力檢查 VRA ( visual reforcement audiometry )

透過聲音刺激配合帶光源的玩偶進行視覺強化訓練形成條件反射，訓練完條件反射後仍用聲、光、玩偶等配合測得嬰幼兒對聲刺激產生反應閾值的一種測聽方法。通常適用於6個月~2歲的嬰幼兒。 測試前準備—訓練受試者建立條件化，給予估計聽閾加上15~20dB刺激聲，當嬰幼兒出現反應給予視覺獎勵，訓練2-3次至嬰幼兒理解後， 正式測試，以找出聽力閾值。測試音可以用語音或是純音。

遊戲聽力檢查 CPA ( conditoning play audiometry )

遊戲測聽是讓幼兒在遊戲過程中完成測聽的一種方法。年齡二到三歲後，孩童就更能配合測試。 遊戲聽力檢查將檢查過程設計成一個遊戲，測試中，可能要求小朋友每聽到一個聲音，就往籃子裡丟一顆球，或者一片片慢慢完成拼圖。 根據年齡、耳朵大小，以及孩子對耳機的接受度不同，可透過喇叭、氣導耳機及／或骨導震盪器來給予測試聲音。使用喇叭時，因為同時測試兩耳，測試的時間會比較短，但也因為無法區分左耳與右耳的聽閾值，效果比較不精確。

語音聽力檢查

上述方法的功用都是用來找出聽力閾值，語音聽力檢查則可以用來找出語音訊號的聽閾值。這個方法對判別聽力損失來說，是很有用的輔助方式，同時可以用來比較不同助聽器或選配方式在兒童身上的效果。測試材料包含單字或語句清單。依兒童的年齡跟語言技巧不同，可以使用不同的測試材料。
